🚀 Deploy Otomatis ke Netlify

Aplikasi ini sudah disiapkan dengan file netlify.toml dan kode siap push ke repository GitHub kamu: ikusmanuwu/efraterbaik.
Langkah Men-trigger Deploy ke Netlify:
  1. Salin file netlify.toml dan index.html ke repository lokal kamu.
  2. Jalankan di terminal repository efraterbaik:
    git add . git commit -m "feat: tambah periode anggaran siklus gajian & netlify deploy" git push origin main
  3. Netlify akan mendeteksi commit baru secara otomatis dan men-deploy web app kamu dalam hitungan detik!
File netlify.toml:
[build] publish = "." [[redirects]] from = "/*" to = "/index.html" status = 200
Script SQL Supabase untuk Periode:
(Opsional) Jalankan supabase_periode.sql di Supabase SQL Editor jika ingin menyimpan konfigurasi periode di database cloud.
